# 기관·업무·프로젝트·토큰 연결표

이 표에는 원문으로 확인한 연결만 넣는다. 연결 등급과 사업 단계의 정의는 [research-principles.md](research-principles.md) 2절과 4절을 따른다. 기관과 사업 관계가 있다는 사실은 토큰을 사야 한다는 뜻이 아니므로, "토큰 언급" 열을 따로 둔다.

행을 추가하거나 바꿀 때는 "확인" 열에 확인 날짜와 확인한 도구를 적는다. 원문을 직접 열어 보지 못한 행은 "미확인"으로 둔다.
