# 미결 사항

아직 정해지지 않은 사항을 모아 둔다. AI는 이 목록의 항목을 임의로 확정하지 않는다. 처리 방법은 다음과 같다.

- 임시 기본값이 있는 항목은 그 값으로 작업을 진행하고, 임시 기본값을 적용했다는 사실을 결과물(PR 설명이나 research 폴더의 README.md)에 적는다.
- 임시 기본값이 "없음"인 항목은 사용자에게 확인한다. 사용자에게 물을 수 없는 실행 환경에서는 그 부분을 진행하지 않고, 진행하지 않은 이유를 결과물에 적는다.
- 사용자가 결정하면 [decisions.md](decisions.md)에 항목을 추가하고, 여기에는 "결정됨 (D-번호)"으로 표시한다.

## Q1. 수집 시스템의 1차 목적

- 선택지: (a) 매매 판단을 돕는 빠른 알림, (b) 가설 검증용 사건 기록의 축적
- 영향: 빠른 경로와 느린 경로 중 무엇을 먼저 만들지가 달라진다.
- 임시 기본값: (b)를 먼저 만들고 (a)를 붙인다. 사건 기록이 쌓여야 알림 기준도 근거를 갖고 정할 수 있기 때문이다.

## Q2. 맥북 사양과 설정

- 필요한 정보: 모델(Apple Silicon 여부), macOS 버전, FileVault 사용 여부, 설치 장소에서 거래소 API(바이낸스 등)에 접속되는지 여부
- 공개 저장소 주의: 이 항목의 답에는 판단에 필요한 수준만 적는다. 일련번호, IP 주소, 공유기 설정, 설치 장소의 주소 같은 세부 정보는 적지 않는다.
- 영향: 로컬 AI 모델을 쓸 수 있는지, 재부팅 후 자동 실행을 어떻게 할지(FileVault와 자동 로그인), 충전 한도 기능을 쓸 수 있는지, 거래소 API에 접속할 수 있는지가 달라진다 ([collector-spec.md](collector-spec.md) 8절).

## Q3. 알림 채널

- 선택지: 텔레그램 봇, 카카오톡 "나에게 보내기", Slack
- 고려 사항:
  - 텔레그램 봇은 설정이 간단하다. 봇으로 알림을 보내는 것은 [collector-spec.md](collector-spec.md) 3절에서 보류한 채널 수집과 다른 기능이다.
  - 카카오톡 "나에게 보내기"는 메모 용도로 설계되어 휴대전화 알림이 오지 않는다 (카카오 데브톡의 카카오 담당자 답변, 2024-11-01). 따라서 바로 알아야 하는 알림을 받는 채널로는 맞지 않는다. 또한 카카오 로그인 토큰이 필요하다. REST API 기준으로 액세스 토큰은 6시간, 리프레시 토큰은 2개월 동안 유효하고, 리프레시 토큰은 만료까지 1개월 이하로 남았을 때부터 갱신할 수 있다. 프로그램이 토큰을 자동으로 갱신하지 못해 리프레시 토큰이 만료되면 다시 로그인해야 한다 ([카카오 로그인](https://developers.kakao.com/docs/ko/kakaologin/common), [카카오톡 메시지](https://developers.kakao.com/docs/ko/kakaotalk-message/common), [카카오 데브톡](https://devtalk.kakao.com/t/topic/126646), 2026-09-30 확인).
  - Slack은 이미 연결된 작업 공간이 있다면 쓸 수 있다.

## Q4. X 처리 방침

- 선택지: (a) v1에서 제외하고 휴대전화 알림으로 보완한다. (b) 소수 계정만 공식 유료 API로 수집한다. (c) 비공식 수집기를 쓴다 (약관 위반과 계정 정지 위험이 있다).
- 주의: (c)는 AGENTS.md의 공개 저장소 주의 사항("이용약관이 자동 수집을 금지하는 출처에는 자동 수집 기능을 구현하지 않는다")과 충돌한다. (c)를 택하려면 사용자가 먼저 그 규칙을 바꿔야 한다.
- 임시 기본값: (a). 1~2주 운영한 뒤 놓친 뉴스를 분석해서 다시 정한다.

## Q5. 기준 브랜치(main) 생성

- 현황: 이 저장소는 2026-09-30에 비어 있는 상태로 만들어졌고, 첫 푸시는 Claude Code 작업 브랜치(`claude/blissful-cerf-rr8n08`)로 이루어졌다. 브랜치가 하나뿐이므로 현재 GitHub 기본 브랜치도 이 브랜치다 (2026-09-30 [GitHub API](https://api.github.com/repos/tlzkrh1029/crypto_institution_research)로 확인). 다른 도구도 지금 이 내용을 읽을 수 있다. 다만 이 브랜치는 이름에서 드러나듯 임시 작업 브랜치이고 Claude Code 세션이 이 브랜치에 계속 푸시하므로, 기준 브랜치로 계속 쓰기에는 불안정하다.
- 선택지: 작업 브랜치의 내용으로 main을 만들고 기본 브랜치로 지정한다. 또는 사용자가 GitHub에서 직접 처리한다.
- 주의: 어떤 도구도 사용자의 명시적인 허락 없이 다른 도구의 작업 브랜치에 푸시하지 않는다. 현재 기본 브랜치는 Claude Code 작업 브랜치이므로, 다른 도구는 새 브랜치에서 작업하고 이 브랜치를 대상으로 PR을 연다.

## Q6. Codex 원본에 딸린 파일

- 파일: `market/README.md`, `market/summary.json`, `catalyst-audit.md`. 이 파일들은 사용자의 Windows 노트북에 있는 Codex 프로젝트 폴더에 있다.
- 선택지: 사용자가 파일을 첨부한다. Codex에서 이 저장소로 직접 푸시한다. 올리지 않는다.
- 추가 위치: 원본 문서의 상대 링크가 작동하도록 `research/2026-09-29-codex-meta-ideas/market/README.md`, `research/2026-09-29-codex-meta-ideas/market/summary.json`, `research/2026-09-29-codex-meta-ideas/catalyst-audit.md`에 원본 그대로 추가한다. 이는 기존 기록 폴더에 파일을 추가하는 예외다. 같은 PR에서 고칠 수 있는 기존 내용은 그 폴더 README.md의 "누락된 딸린 파일" 절 하나뿐이며, 이 절에는 파일을 추가한 날짜와 도구를 적는다. 파일에 로컬 경로나 개인 정보처럼 공개하면 안 되는 내용이 있으면, 추가하기 전에 사용자에게 알린다.
- 영향: 올리지 않으면 [원본 문서](../research/2026-09-29-codex-meta-ideas/research-and-ideas.md)의 해당 링크가 작동하지 않는다.

## Q7. 고정 비교 대상 종목과 대조군

- 필요한 것: 기관 인프라 후보 8~12개, 같은 서사를 가졌지만 반응이 약한 대조군, 같은 시총 구간에서 서사와 무관한 대조군
- 초안: LINK, XLM, HBAR, QNT, ONDO(관심 표본), XRP(같은 서사의 대조군). 나머지 후보와 무관 대조군은 사용자와 함께 정한다.
- 주의: 2026-09-30 검토에서 사후에 조회한 AVAX, ENA, ALGO는 예시일 뿐이다. 오른 것을 보고 고른 종목이므로 대조군으로 쓰지 않는다.

## Q8. 느린 경로의 AI 해석 방식

- 선택지: 구독 CLI (Claude Code 또는 Codex), API, 로컬 모델, AI 없이 사람이 검토
- 고려 사항: [collector-spec.md](collector-spec.md) 7절 참고. 구독 CLI의 요금 조건은 바뀔 수 있다.

## Q9. 저장소 공개 여부와 작성 지침 전문 공개

- 현황: 저장소는 공개 상태이며(D-004), 사용자의 한국어 작성 지침 전문이 docs/writing-style-ko.md에 공개되어 있다(D-005). 둘 다 잠정 결정이다.
- 선택지: 공개 유지, 비공개 전환, 작성 지침만 비공개 저장소로 이동

## Q10. 이용 조건에 제약이 있거나 불명확한 무료 수집원

- 대상: 텔레그램 공개 채널(사용자 계정으로 로그인하는 API 클라이언트), Google News RSS 검색, PR Newswire RSS, Business Wire RSS, GlobeNewswire RSS, DTCC 사이트맵(보도자료 목록)
- 고려 사항: 텔레그램 약관은 텔레그램 데이터를 AI의 학습, 개발, 배포에 쓰는 것과 사용자로서의 통상적인 이용을 벗어난 콘텐츠 접근을 금지한다. Google News RSS는 피드에 개인 피드 리더에서 개인적·비상업적으로 표시하는 용도 외의 사용을 금지한다고 적혀 있다. PR Newswire는 자동 접근, 데이터베이스 저장, AI 이용을 금지한다. Business Wire와 GlobeNewswire, DTCC 사이트맵은 이용 조건이 불명확하다. 자세한 내용은 [collector-spec.md](collector-spec.md) 3절과 [2026-09-30 데이터 출처 점검](../research/2026-09-30-claude-data-source-check/README.md)에 있다.
- 선택지: 계속 보류한다. 제목과 링크만 로컬에 저장하고 AI 해석에 보내지 않는 조건으로 개인 열람 수준에서만 쓴다. 배포처에 서면 허락을 요청한다. 쓰지 않기로 확정한다.
- 영향: 기관과 크립토 프로젝트의 연결 발표는 주로 보도자료 배포처로 나온다. 이 출처들을 보류하면 수집기는 규제기관과 일부 기관의 공식 피드만 자동으로 확인한다.
- 임시 기본값: 보류한다.

## Q11. CoinGecko 스냅숏 CSV의 공개

- 현황: research/2026-09-30-claude-review/에 관심 종목 12개의 CoinGecko 값을 담은 CSV가 있다. CoinGecko API 약관은 데이터 저장을 권장하지 않고, 약관이 허용한 범위 밖의 복제와 저장을 금지하며, 표시할 때 출처 표기를 요구한다 ([CoinGecko API 약관](https://www.coingecko.com/en/api_terms), 2026-09-30 확인).
- 선택지: 출처 표기와 함께 유지한다. 삭제하고 계산 결과만 남긴다 (스크립트로 새 스냅숏은 다시 만들 수 있다).
- 임시 기본값: 출처 표기와 함께 유지한다. 재현에 필요한 소량의 연구용 스냅숏이기 때문이다.
